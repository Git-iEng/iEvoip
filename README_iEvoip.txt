iEvoip Website - Updated Django Project

This project uses the Boiler website layout/design as the base and has been converted to iEvoip.

Main changes:
- Boiler branding/content replaced with iEvoip.
- Home hero updated with iEvoip business phone-system content and a softphone preview.
- "Types" replaced by "Features" using iEvoip feature content.
- "Services" replaced by "How It Works" using the iEvoip call-flow content.
- Old standalone Boiler Workflow section removed.
- Boiler application cards replaced with iEvoip use cases.
- Header/footer navigation updated to Features / How It Works / About / Contact.
- iEvoip logo and product assets added.
- Inquiry/privacy/email wording updated from Boiler to iEvoip.
- Sitemap and host settings updated for ievoip.ieng.tech.
- Existing Django contact and demo form logic retained.

Run on Windows:
1. Open Command Prompt/PowerShell in this folder.
2. Create/activate a Python virtual environment if required.
3. Install dependencies: pip install -r requirements.txt
4. Run: python manage.py runserver 0.0.0.0:8000

Then open http://127.0.0.1:8000/
